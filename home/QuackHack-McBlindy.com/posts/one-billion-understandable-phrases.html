What a billion actually means

yo is a natural language to shell script translator. You speak or type a sentence. It runs exact and fuzzy pattern matching against a set of templates, resolves the parameters, and executes the corresponding script. No command list to memorize. No aliases to look up. Just a sentence.

A billion is easy to say and hard to picture. So let's make it concrete.

The math

yo doesn't have a billion sentences written into it. It has 8,043 patterns - human-written templates with slots. What turns those 8,043 patterns into 1,070,236,143 phrases is the parameter space.

Every slot in a pattern can be filled by every value that slot accepts. When a pattern says "deploy {host}" and {host} can be any of your machines, that's one pattern generating many sentences. When a pattern says "play {track} on {speaker}" and {track} has 1,024 values and {speaker} has 24, that's one pattern generating 24,576 sentences.

Stack enough slots across enough scripts, and the multiplication does what multiplication does. 8,043 patterns × ~133,064 variations per pattern = over a billion distinct sentences the runtime matcher recognizes.

What understandable means here

The billion is not "sentences the system will attempt." It's "sentences the system will correctly recognize, resolve, and run." That's a much smaller, much more honest number.

Not "weekend work"

8,043 patterns is a lot to hand-write. 133,064 phrases per pattern is a lot of grammar to get right - plural, word order, synonyms, optional words, alternative words. Every new pattern multiplies against every existing parameter list, and every new parameter value multiplies against every existing pattern. The phrase count grows quadratically, initially the work to keep it accurate grew with both sides, that's before I implemented fuzzy sentence conflict detection at compile-time.

That's what hitting one billion really means: not that the matcher is fast - 97 ms average across 1,467 runs is nice but cheap - but that the vocabulary underneath it is dense enough. The multiplication naturally clears a billion.

And it helps that 74 of the 103 scripts expose their vocabulary to the voice layer. Those 74 are the scripts that can be spoken to, and they're what feeds the phrase count. The other 29 are infrastructure - hooks, generators, helpers - that nobody needs to say out loud.

The system is not smart. It's thorough.
And thorough, at this scale, is its own kind of milestone.
